How I work.

  1. 01Discovery

    You tell me how things work today, where they get stuck and who will use the system. That tells us what to build first.

  2. 02A small first version

    We define the smallest version that is already useful, with its screens and data, and start there.

  3. 03Short iterations

    Every one or two weeks you see progress on a staging link and we adjust it with real use.

  4. 04Going live

    It ships on your domain and your accounts, with the code and documentation so you don’t depend on me.

FAQ.

Why custom instead of an existing tool?

If an existing tool solves your problem, I’ll tell you. Custom pays off when your process is what sets you apart, or when you’re paying for several tools that don’t talk to each other.

Who maintains it afterwards?

I can keep maintaining it on a monthly basis, or hand it over documented so someone else can take it.

Do you work with clients outside Argentina?

Yes, remotely and in English. I’m based in Buenos Aires (GMT-3), which overlaps well with US and European working hours.

How long does it take?

It depends on scope. That’s why we start with the smallest useful version and build on something that already works.

How much does it cost?

After the first call and discovery I send you a quote for that first version.
