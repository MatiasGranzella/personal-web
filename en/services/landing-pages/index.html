No. I build the site in code: it loads faster, doesn’t depend on plugins and doesn’t need a template subscription.

I handle small changes. If you need to edit often, we set it up so you can do it yourself.

I leave it ready for Google to index and for people nearby to find. Nobody serious can promise you the top spot, but nothing technical will be missing.
